# УВМ: ассемблер и интерпретатор (вариант 10)

Учебный проект: ассемблер и интерпретатор для учебной виртуальной
машины (УВМ). Проект разрабатывается поэтапно, каждый этап описан
ниже. Тег `stage-1` указывает на состояние после этапа 1: в нем режим
`--test` печатал поля команд, а не байты (`git checkout stage-1`,
вернуться: `git switch -`).

Требуется Python 3.8 или новее. Сторонних библиотек нет.

## 2. Язык ассемблера

Появился на этапе 1. Одна команда на строку, формат CSV:
`мнемоника,операнд`.

| Мнемоника | A | Операнд B                  | Диапазон B       | Размер  |
|-----------|---|----------------------------|------------------|---------|
| `load`    | 4 | константа (биты 3-32)      | 0 .. 1073741823  | 5 байт  |
| `read`    | 7 | смещение (биты 3-13)       | 0 .. 2047        | 2 байта |
| `write`   | 5 | нет                        | -                | 1 байт  |
| `sqrt`    | 6 | смещение (биты 3-13)       | 0 .. 2047        | 2 байта |

Правила:
- мнемоники не зависят от регистра (`load` = `LOAD`);
- операнд записывается десятичным числом или с префиксом `0x`,
  `0o`, `0b`;
- у `write` операнда нет;
- пустые строки пропускаются;
- строка, начинающаяся с `#`, считается комментарием.

## 3. Машинный код

Появился на этапе 2. Команда кодируется числом `A | (B << 3)`: поле A
занимает биты 0-2, поле B начинается с бита 3. Число записывается в
байты от младшего к старшему (little-endian). Длина команды зависит от
кода операции (см. таблицу выше). Пример, `load,405`:
`4 + (405 << 3) = 0x0CAC` -> байты `AC 0C 00 00 00`.

## 4. Модель УВМ

Появилась на этапе 3, команда `sqrt` добавлена на этапе 4.

- **Память команд**: байты программы из двоичного файла, только
  чтение. Выполнение идет с позиции 0 до конца.
- **Память данных**: 4096 ячеек (`DATA_MEMORY_SIZE` в `src/isa.py`),
  изначально нули. Обращение за пределы `0..4095` - ошибка. Ячейка
  хранит целое число.
- **Стек**: отдельная структура, хранит промежуточные значения.

Память команд и память данных разделены.

Действие команд:

| Команда   | Действие                                              |
|-----------|-------------------------------------------------------|
| `load B`  | положить `B` на стек                                  |
| `read B`  | снять адрес, положить на стек `data[адрес + B]`       |
| `write`   | снять значение, затем адрес; `data[адрес] = значение` |
| `sqrt B`  | снять адрес, положить на стек целую часть корня из    |
|           | `data[адрес + B]` (значение в памяти не меняется)     |

Чтобы записать значение V по адресу X: `load,X`, `load,V`, `write`.
Чтобы сохранить корень в память: `load,приемник`, `load,база`,
`sqrt,индекс`, `write`. Если приемник совпадает с элементом источника,
корень записывается на место исходного числа.

## 5. Описание функций и настроек

### Ассемблер (`src/assembler.py`, этапы 1-2)

| Аргумент | Описание                                                   |
|----------|------------------------------------------------------------|
| `source` | путь к исходному файлу с программой (CSV)                  |
| `output` | путь к двоичному файлу-результату                          |
| `--test` | режим тестирования: вывести машинный код в байтах          |

После работы выводится размер двоичного файла в байтах.

### Интерпретатор (`src/interpreter.py`, этап 3)

| Аргумент              | Описание                                      |
|-----------------------|-----------------------------------------------|
| `binary`              | путь к бинарному файлу программы              |
| `dump`                | путь к CSV-файлу для дампа памяти             |
| `--range FIRST LAST`  | диапазон адресов дампа, границы включаются    |

Формат дампа: заголовок `address,value`, затем строка на адрес.

### Генератор программ (`tools/gen_vector_program.py`, этап 5)

| Аргумент | Описание                                                     |
|----------|--------------------------------------------------------------|
| `output` | путь к создаваемому файлу программы (CSV)                    |
| `base`   | адрес начала вектора в памяти данных                         |
| `values` | ровно 10 чисел - исходный вектор                             |

Код возврата всех программ: `0` при успехе, `1` при ошибке
(сообщение выводится в stderr).

### Функции

`src/isa.py`
- `COMMANDS` - команды: мнемоника -> (код операции, ширина операнда,
  размер) (этап 1, размеры - этап 2).
- `SIZES` - размер команды по коду операции (этап 2).
- `OPERAND_BITS`, `OPCODE_MASK`, `DATA_MEMORY_SIZE` (этап 3).

`src/translator.py` (этап 1)
- `parse_operand(text, bits, line_no)` - текст операнда в число с
  проверкой диапазона.
- `is_skippable(row)` - пустая строка или комментарий.
- `translate_row(row, line_no)` - строка CSV в команду-словарь.
- `assemble_text(lines)` - вся программа в список команд.
- `AsmError` - ошибка ассемблирования (с номером строки).

`src/encoder.py` (этап 2)
- `encode_instruction(instruction)` - команда в байты.
- `encode_program(program)` - программа в список байтовых команд.

`src/assembler.py` (этапы 1-2)
- `build_parser()`, `read_source(path)`, `main(argv)` - этап 1.
- `write_binary(path, data)`, `format_bytes(code)`, `run(args)` -
  этап 2.

`src/decoder.py` (этап 3)
- `decode_instruction(code, position)` - байты в команду и позиция
  следующей команды.
- `DecodeError` - неизвестный код операции или обрезанная команда.

`src/alu.py` (этап 4)
- `sqrt(value)` - целая часть квадратного корня (округление вниз).

`src/vm.py` (этапы 3-4)
- `Machine` - состояние УВМ: `code`, `data`, `stack`.
  Методы: `fetch` (этап 4), `op_load`, `op_read`, `op_write`,
  `op_sqrt` (этап 4), `step`, `run`, `dump`.
- `VMError` - ошибка выполнения (пустой стек, адрес вне памяти,
  неверный диапазон, команда без обработчика).

`src/interpreter.py` (этап 3)
- `build_parser()`, `read_binary(path)`, `write_dump(path, rows)`,
  `run(args)`, `main(argv)`.

`tools/gen_vector_program.py` (этап 5)
- `init_lines(base, values)` - команды записи вектора в память.
- `sqrt_lines(base, length)` - команды замены элементов корнями.
- `program_lines(base, values)` - полный текст программы.
- `build_parser()`, `main(argv)` - CLI генератора.

## 6. Сборка и запуск тестов

Сборка не требуется. Команды (из корня репозитория):

```
make test     # запуск тестов
make run      # этап 2: ассемблирование spec_tests.csv, режим --test
make copy     # этап 3: копирование массива и дамп памяти
make sqrt     # этап 4: вычисление корней и дамп памяти
make vectors  # этап 5: три программы над вектором из 10 чисел
```

Без `make` (Linux, WSL, macOS):

```
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 src/assembler.py examples/vector_mixed.csv out.bin
python3 src/interpreter.py out.bin mixed.dump.csv --range 100 109
```

Без `make` (Windows PowerShell):

```
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python src/assembler.py examples/vector_mixed.csv out.bin
python src/interpreter.py out.bin mixed.dump.csv --range 100 109
```

Создание примеров этапа 5 (генератор записывает файл в UTF-8):

```
python tools/gen_vector_program.py examples/vector_squares.csv 0 1 4 9 16 25 36 49 64 81 100
python tools/gen_vector_program.py examples/vector_mixed.csv 100 0 2 3 8 15 24 50 99 101 12345
python tools/gen_vector_program.py examples/vector_large.csv 4086 1073741823 1000000000 999999999 123456789 65536 65535 1000000 99980001 99980000 1
```

### Этап 5

Каждая программа сначала записывает вектор из 10 чисел в память, затем
10 раз выполняет блок «заменить элемент его корнем». Для элемента 9
примера `vector_mixed` (база 100, число 12345):

```
load,109    # стек: [109]            адрес результата (тот же элемент)
load,100    # стек: [109, 100]       база вектора
sqrt,9      # data[100 + 9] = 12345, стек: [109, 111]
write       # снять 111 и 109, data[109] = 111
```
