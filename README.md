# Ассемблер учебной виртуальной машины (УВМ), вариант 10

## 1. Общее описание

Проект содержит ассемблер для учебной виртуальной машины (УВМ).
Исходная программа записывается в формате CSV, транслируется во
внутреннее представление (список команд с полями `A` и `B`), затем
в машинный код, который записывается в двоичный файл.

Реализованы этапы 1-2: разбор текста программы и формирование
машинного кода. Интерпретатор (этапы 3-5) будет добавлен позже.

Требуется Python 3.8 или новее. Сторонних библиотек нет.

### Язык ассемблера

Одна команда на строку, формат CSV: `мнемоника,операнд`.

| Мнемоника | A | Операнд B                  | Диапазон B       | Размер  |
|-----------|---|----------------------------|------------------|---------|
| `load`    | 4 | константа (биты 3-32)      | 0 .. 1073741823  | 5 байт  |
| `read`    | 7 | смещение (биты 3-13)       | 0 .. 2047        | 2 байта |
| `write`   | 5 | нет                        | -                | 1 байт  |
| `sqrt`    | 6 | смещение (биты 3-13)       | 0 .. 2047        | 2 байта |

Правила:
- мнемоники не зависят от регистра (`load` = `LOAD`);
- операнд записывается десятичным числом или с префиксом `0x`,
  `0o`, `0b`;
- у `write` операнда нет;
- пустые строки пропускаются;
- строка, начинающаяся с `#`, считается комментарием.

Семантика команд:
- `load` - поместить константу на вершину стека;
- `read` - взять адрес с вершины стека, прочитать значение памяти
  по адресу `адрес + смещение`, поместить его на стек;
- `write` - снять значение с вершины стека и записать его в память
  по адресу, снятому с вершины стека;
- `sqrt` - вычислить квадратный корень значения памяти по адресу
  `адрес (с вершины стека) + смещение`, поместить результат на стек.

### Машинный код

Команда кодируется числом `A | (B << 3)`: поле A занимает биты 0-2,
поле B начинается с бита 3. Число записывается в байты от младшего
к старшему (little-endian). Длина команды зависит от кода операции
(см. таблицу выше). Например, `load,405`:
`4 + (405 << 3) = 0x0CAC` -> байты `AC 0C 00 00 00`.

## 2. Описание функций и настроек

### Аргументы командной строки (`src/assembler.py`)

| Аргумент   | Описание                                              |
|------------|-------------------------------------------------------|
| `source`   | путь к исходному файлу с программой (CSV)             |
| `output`   | путь к двоичному файлу-результату                     |
| `--test`   | режим тестирования: вывести машинный код в байтах,    |
|            | по одной строке на команду                            |

После работы на экран выводится размер двоичного файла в байтах.
Код возврата: `0` при успехе, `1` при ошибке (сообщение выводится
в stderr).

### Функции

`src/isa.py`
- `COMMANDS` - таблица команд: мнемоника -> (код операции, ширина
  операнда в битах, размер команды в байтах).
- `SIZES` - размер команды по коду операции.

`src/translator.py`
- `parse_operand(text, bits, line_no)` - текст операнда в число с
  проверкой диапазона.
- `is_skippable(row)` - пустая строка или комментарий.
- `translate_row(row, line_no)` - строка CSV в команду-словарь.
- `assemble_text(lines)` - вся программа в список команд.
- `AsmError` - ошибка ассемблирования (с номером строки).

`src/encoder.py`
- `encode_instruction(instruction)` - команда в байты.
- `encode_program(program)` - программа в список байтовых команд.

`src/assembler.py`
- `build_parser()` - разбор аргументов командной строки.
- `read_source(path)` - чтение исходного файла.
- `write_binary(path, data)` - запись двоичного файла.
- `format_bytes(code)` - байты в вид `0xAC, 0x0C`.
- `run(args)` - ассемблирование, запись файла, вывод результатов.
- `main(argv)` - точка входа.

## 3. Сборка и запуск тестов

Сборка не требуется. Команды (из корня репозитория):

```
make test     # запуск тестов
make run      # ассемблирование examples/spec_tests.csv в режиме --test
```

Без `make` (Linux, WSL, macOS):

```
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 src/assembler.py examples/spec_tests.csv out.bin --test
```

Без `make` (Windows PowerShell):

```
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python src/assembler.py examples/spec_tests.csv out.bin --test
```

## 4. Примеры использования

Программа `examples/spec_tests.csv`:

```
load,405
read,279
write
sqrt,657
```

Запуск:

```
python3 src/assembler.py examples/spec_tests.csv out.bin --test
```

Вывод (совпадает с тестами спецификации):

```
0xAC, 0x0C, 0x00, 0x00, 0x00
0xBF, 0x08
0x05
0x8E, 0x14
Размер двоичного файла: 10 байт
```

Без `--test` выводится только размер файла. Пример ошибки:

```
$ python3 src/assembler.py bad.csv out.bin
Ошибка: строка 2: неизвестная команда 'foo'
```
